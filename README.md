# FraudShield — Transaction Risk Analytics

A portfolio application combining Python, machine learning,
FastAPI, SQLite, and a browser dashboard.

## Features
- Synthetic-data Random Forest demonstration model
- Transaction risk scoring REST API
- Interactive dashboard
- SQLite prediction history
- Automated tests
- Docker support

## Run locally
pip install -r requirements.txt
uvicorn fraudshield.app:app --reload

Open http://127.0.0.1:8000

## Run tests
pytest -q

## API documentation
http://127.0.0.1:8000/docs

## Limitations
This is a demonstration system trained on synthetic labels
generated by rules. Its probabilities are not calibrated or
validated against real-world fraud. Do not use it for real
financial decisions.
